# Speed Ease — Premiere Pro panel

תוסף (CEP panel) לפרמיר שמחיל גרף **מהירות** (speed graph, לא value) על keyframes.

## התקנה
- **Windows:** דאבל-קליק על `install-windows.bat`
- **Mac:** `bash install-mac.sh`

ואז להפעיל מחדש את פרמיר → `Window > Extensions > Speed Ease`.

## שימוש
1. מסמנים קליפ בטיימליין.
2. שמים את הסמן (playhead) **בין שני ה-keyframes** שרוצים.
3. מכוונים את הגרף ולוחצים **Apply**. הגרף מוחל על כל המאפיינים המונפשים בקליפ שיש להם keyframes סביב הסמן.

| שליטה | מה עושה |
|---|---|
| סליידר ימני ← שמאלה | מגדיל את ה-influence הימני — שיא המהירות חד יותר וזז לצד שמאל |
| סליידר שמאלי → ימינה | מגדיל את ה-influence השמאלי — שיא המהירות חד יותר וזז לצד ימין |
| אייקון באמצע | גרירה ימינה/שמאלה = שני הצדדים זהים (ימינה חד יותר, שמאלה רך יותר). קליק = משווה לממוצע |
| מספרים בצדדים | ערך מדויק 1–100 (%). חצים ↑↓ / גלגלת לכיוונון, Shift = ×10 |
| Shift בזמן גרירה | כיוונון עדין |
| העתקה | שומר את הגרף (נשמר גם אחרי סגירה) |
| הדבקה | מחיל את הגרף שהועתק על ה-keyframes שסביב הסמן — מותאם אוטומטית למשך ולערכים החדשים |
| קו אלכסוני | מסיר את ה-ease ומחזיר לתנועה לינארית |

## ספריית גרפים
כפתור הספרייה (אייקון הספרים) פותח רשימה של הגרפים השמורים, כל אחד עם תצוגה מקדימה קטנה של גרף המהירות.

| פעולה | איך |
|---|---|
| שמירת הגרף הנוכחי | `+` → מקלידים שם → Enter (Esc מבטל) |
| טעינת גרף | קליק על השורה (חוזר למסך הראשי, ואז Apply) |
| שינוי שם | דאבל-קליק על השורה, או אייקון העיפרון |
| עדכון הגרף השמור לגרף הנוכחי | אייקון החץ המעגלי |
| מחיקה | ✕ ואז קליק נוסף לאישור |

הספרייה נשמרת אצלך במחשב ונשארת גם אחרי סגירת פרמיר.

חזרה עם הסמן לקטע שכבר הוחל עליו גרף טוענת את הגרף שלו לעורך.

## איך זה עובד (ומגבלות של פרמיר)
ה-API של פרמיר **לא מאפשר** לסקריפטים לקבוע את ידיות ה-bezier (speed/influence) של keyframe, וגם **לא מאפשר לקרוא אילו keyframes מסומנים**. לכן:
- הקטע נבחר לפי הקליפ המסומן + מיקום ה-playhead (במקום סימון keyframes).
- הגרף "נאפה": נוצר keyframe לינארי בכל פריים בין שני ה-keyframes, עם ערכים שמחושבים מעקומת ה-bezier
  `P0(0,0) P1(a,0) P2(1−b,1) P3(1,1)` (a = influence שמאלי, b = ימני — כמו ב-After Effects).
  שני ה-keyframes המקוריים לא זזים ולא משתנים.
- Undo בפרמיר מבטל keyframe אחד בכל פעם — כדי לבטל השתמשו בכפתור ההסרה (קו אלכסוני).
